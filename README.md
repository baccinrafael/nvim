 My nvim config because i realized VSCode is garbage for anything other than web dev and vibe coding bullshit.

 This config is nothing more than LazyVim with more (or less) plugins for some of my needs.
 The main things i changed are:
 - Typst with live preview support
 - Live preview for web dev
 - P5.js library support
 - LÖVE2D support
